# Vendored pstack resources

Source: [michael-denyer/pstack-claude](https://github.com/michael-denyer/pstack-claude), tag `v0.9.93`, plugin directory `plugins/pstack`. The exact commit, upstream paths, and SHA-256 checksums are recorded in `upstream.json`. All upstream files are byte-for-byte copies; `README.md` is the upstream plugin README.

This directory is the portable plugin resource root. It contains all 174 files under `skills/` (63 skill entry points, including every bundled script, reference, playbook, test, dependency manifest, and lockfile), four agent definitions, ten effort-agent definitions, `hooks/session-start-context.md`, the unchanged Claude plugin manifest and icon, plugin artwork, and `models.json`. No global skills were copied. Runtime hook executables/configuration, Pi extensions, other runtime manifests, workflows, Git metadata, credentials, caches, and installation state are deliberately excluded. Consumers install or load these resources; vendoring does not execute scripts or install their dependencies. Scripts retain upstream requirements such as Node.js, Bun, and GitHub CLI.

Redistribution is under MIT. Preserve `LICENSE` (Lauren Tan and Michael Denyer), `LICENSE-cursor-team-kit` and `LICENSE-thermos` (Cursor), `NOTICE-skills.md`, and the notices already bundled under `skills/poteto-mode/references/licenses/`. The upstream README and notices retain their original links and attribution; upstream documentation links may point to the upstream default branch rather than this pinned copy. There are no local edits to upstream content and no known licensing blockers.

To update, fetch the explicitly chosen upstream tag into a temporary checkout, verify its commit and plugin version, copy the same selected paths without editing their bytes or executable permissions, and regenerate `upstream.json`. Verify every recorded checksum and source path, all manifest agent paths, the complete skills tree, and the absence of credentials and installation artifacts before handing the resources to the bootstrap consumer. Keep maintained source identifiers and checksums in machine-readable metadata, not prose.
